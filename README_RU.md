## 📡 Проблема в сетях LoRa и Meshtastic

В mesh-сетях LoRa (в частности на пресетах **Medium-Fast** и **Long-Fast**):
* **Ограничение MTU:** ~**237 байт** на один кадр полезной нагрузки.
* **Эфирное время (Airtime) критично:** Фрагментация на несколько пакетов резко повышает шанс коллизий и потерь при ретрансляциях в mesh-сети.
* **Стандартные алгоритмы не работают на малых пакетах:** Gzip и Zstandard добавляют 10–25 байт заголовков и таблиц, из-за чего короткие сообщения (<100 байт) **увеличиваются** в размере.

**`lorapress`** разработан специально под физику LoRa: минималистичный 1-байтный заголовок, встроенные частотные таблицы для русского и английского языков, словарь радиосленга, упаковка JSON в битовый поток и кластерный микро-кодек для передачи изображений.

## 🛠 Особенности

* **Автоматический выбор стратегии (Algorithm Race):** Движок пробует все релевантные алгоритмы и выбирает самый компактный вариант.
* **`no_std` совместимое ядро:** Библиотека `lorapress-core` готова к запуску прямо на микроконтроллерах (ESP32, nRF52840, STM32) и в WebAssembly (WASM).
* **Префиксно-свободный суббайтовый кодек `TextMicro`:** Высокая плотность кириллицы и встроенный словарь радиокоманд.
* **`JsonCompact` микро-схема:** Координаты GPS упаковываются с фиксированной запятой (точность 1.1 см занимает 4 байта на координату), а ключи кодируются 5-битными индексами.
* **Кластеризация изображений 4x4:** Однородные области кодируются 2 битами на блок, что позволяет передать пиктограмму или фрагмент карты в 1 LoRa-пакете.
* **Разделение каналов Miren (ARKit 52 Blendshapes + Audio):** Специализированный кодек для видео-кружков `miren`, сжимающий 5 секунд анимированной мимики 3D-аватара всего в 58 байт (1 пакет LoRa!).
* **Физический калькулятор Airtime:** Точный расчет времени в эфире для параметров модуляции LoRa.

## 📦 Структура Workspace

* **`lorapress-core`**: Базовое `no_std` ядро со всеми кодеками, энвелопом и битовым потоком.
* **`lorapress-cli`**: Универсальная консольная утилита (сжатие, распаковка, конвертация картинок, инспекция).
* **`lorapress-bench`**: Стенд сравнения производительности с Gzip и Zstandard.

## 💻 Использование CLI

```bash
# 1. Сжать текст в HEX для отправки в LoRa
lorapress compress -t "База, как слышно? Еду на точку 5. Прием." --hex

# 2. Распаковать пакет из HEX
lorapress decompress -x 22055047814b7e84a29a

# 3. Сжать картинку (PNG/JPG) в 1-битный кластерный пакет
lorapress image -i map_icon.png -s 32 --hex

# 4. Проинспектировать полезную нагрузку и рассчитать Airtime в Medium-Fast
lorapress inspect -t '{"lat":55.7512,"lon":37.6184,"alt":154,"batt":89,"temp":21.4}'
```
